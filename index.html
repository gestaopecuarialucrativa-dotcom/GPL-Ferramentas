🔵 Diagnóstico Bluetooth — Balança
Não conectado
1
Verifique o driver Bluetooth do notebook
No Windows: abra o Gerenciador de Dispositivos → expanda "Bluetooth" → se tiver ⚠️ amarelo no adaptador, o driver precisa ser atualizado.
Win + X → Gerenciador de Dispositivos → Bluetooth
2
Atualize o driver Bluetooth
Clique com botão direito no adaptador Bluetooth → Atualizar driver → "Pesquisar drivers automaticamente". Se não encontrar, veja a marca do notebook abaixo:
Dell → dell.com/support | Lenovo → support.lenovo.com | HP → support.hp.com | Asus → asus.com/support
3
O Chrome precisa de permissão para Bluetooth
O sistema usa Web Bluetooth API. O Chrome bloqueia por padrão em alguns sistemas. Para liberar:
chrome://flags/#enable-web-bluetooth → Enabled → Reiniciar Chrome
4
A balança precisa estar em modo pareamento
Ligue a balança e coloque em modo Bluetooth (geralmente segurando o botão por 3-5 segundos até o LED piscar azul). Fique a menos de 2 metros da balança no momento do pareamento.
5
Se ainda não conectar — use o Android
O sistema funciona 100% no celular Android com Chrome. Se o notebook travar, abra pelo celular — mesmos dados, mesma sincronização.
Acesse pelo celular: gestaopecuarialucrativa-dotcom.github.io/...
